meeoowww.

iOS Shortcut

Overview

This shortcut lets you share a link from any app (YouTube, SoundCloud, TikTok, etc.) and send it directly to downer for download.

Setup

  • Open the Shortcuts app on your iPhone/iPad
  • Create a new shortcut
  • Add these actions in order:

1. Get Text from Input (share sheet receives the URL)

2. URL — set it to https://idowner.vercel.app/api/download

3. Get Contents of URL — method: POST, headers: Content-Type: application/json, request body: {"url": Shortcut Input, "mode": "audio", "format": "mp3"}

4. Save File — save the response to Files (On My iPhone)

Usage

Tap the share button in any app → select this shortcut → file downloads to your device.
